# Personality Training Metadata

Dataset files are organized at the `etl/datasets/` level by processing stage:

| stage | folder |
| --- | --- |
| source data | `etl/datasets/원천 데이터/` |
| intermediate data | `etl/datasets/중간 가공 데이터/` |
| ready-to-use data | `etl/datasets/실사용 데이터/` |

This `personality_training/` folder keeps curation notes and historical metadata for the MBTI tendency modeling dataset.
