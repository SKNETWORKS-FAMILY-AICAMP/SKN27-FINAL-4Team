# Ready-to-Use Data

This folder stores final datasets intended for embedding, model training, validation, or evaluation.

## Contents

| path | note |
| --- | --- |
| `epinfomax_mbti_korean_4axis/` | Korean MBTI dataset cleaned for direct MBTI leakage and expanded to `EI`, `NS`, `FT`, and `JP` axis labels. |

For embedding, use only the `text` column as model input. Keep label columns as supervised targets.
