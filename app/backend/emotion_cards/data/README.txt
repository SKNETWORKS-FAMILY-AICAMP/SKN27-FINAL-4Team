빈틈사이 오늘의 마음 카드 — 장면 매핑 CSV 데이터

구조
사용자 입력 → LLM 구조화(01,02,03,24) → 안전 검사(19) → 명시 정보 우선 → 사건(13) → 필요(15) → 에너지(14) → 감정(12) → 관심사(16) → 문장(18) → 스타일(11) → 프롬프트 조립(22) → 이미지 생성 모델

핵심 원칙
- LLM은 사용자의 말을 이해하고 구조화합니다.
- 매핑 데이터가 하늘·공간·행동·소품·문장을 결정합니다.
- 그림체는 장면 내용과 분리되어 style_id만 변경합니다.
- 사용자가 직접 말한 장소·행동·소품·기억이 가장 우선입니다.
- primary_emotion은 기쁨·슬픔·분노·불안 4개만 사용합니다.
- 중립·모호함·복합은 state_tags, valence, analysis_status로 처리합니다.
- 이미지 안에 문구를 생성하지 않고 UI/Canvas에서 별도 합성합니다.
- CSV 배열 값은 | 로 구분하며 모든 파일은 UTF-8-SIG입니다.

권장 구현
1. CSV를 DB seed로 upsert하거나 시작 시 캐시에 적재
2. 각 후보에 21_conflict_priority_rules.csv 점수를 적용
3. 적용 rule_id를 mapping_reason_codes로 저장
4. 25_scene_mapping_test_cases.csv로 회귀 테스트
5. 사용자가 수정한 태그와 재생성 이력을 추후 규칙 개선에 활용
