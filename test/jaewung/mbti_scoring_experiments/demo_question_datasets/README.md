# Demo Question Datasets

`demo_data.py`에 사용했거나 사용 중인 월간 MBTI 질문-답변 데이터셋 보관 폴더입니다.

| file | dataset | purpose |
| --- | --- | --- |
| `previous_demo_question_responses.md` | legacy demo dataset | 질문 교체 전 초기 데모 질문-답변 보관본 |
| `current_demo_question_responses_v2_axis5_20260703.md` | `demo_questions_v2_axis5_20260703` | 축별 5문항, ISFJ 또는 J/P 경계형 검증용 |
| `current_demo_question_responses_v3_jp_p_adjusted_20260703.md` | `demo_questions_v3_jp_p_adjusted_20260703` | JP 답변을 P 방향으로 조정한 ISFP 검증용 현재 데이터셋 |
| `current_demo_question_responses_v4_jp_mixed_j_rebalanced_20260703.md` | `demo_questions_v4_jp_mixed_j_rebalanced_20260703` | v3 대비 JP 일부 답변을 J 방향으로 재조정한 혼합형 검증용 현재 데이터셋 |

현재 실행 태그는 `run_experiment.py`의 `CURRENT_DEMO_DATASET`에서 관리합니다.
