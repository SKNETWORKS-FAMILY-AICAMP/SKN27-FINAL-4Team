## 3. 실험 ① — 모델 × 사용 방식 (4조합)

## 4. 실험 ② — 데이터셋 추가 (승자 조합 기준 ablation)

> 원칙: "추가하면 잘될 것"이라 가정하지 않는다. **실험으로 확인하고, 오르는 것만 채택.**
> (라벨 체계·문체가 다르면 오히려 하락 가능)

| 조합 | 데이터 | 확보 상태 | 유의점 |
|---|---|---|---|
| 기준선 | 감성대화 58,234 | ✅ | — |
| +웰니스 | AI Hub 웰니스 대화 스크립트 | ✅ 보유 | 상담 의도 라벨 → 4모드 매핑 규칙 필요 |
| +음성전사 | AI Hub 감정 대화 음성 (텍스트 전사) | ✅ 보유 | 7감정 → 4모드 매핑 |
| +KOTE | 한국어 온라인 댓글 5만 건 (44감정) | 공개 다운로드 | 44 → 4모드 매핑 · 라이선스 공개형 |

- **주의**: 현 데이터는 전부 크라우드 작성체 — 같은 스타일 추가는 한계 효용 체감. 장기적으로 가장 값진 추가 데이터는 **실사용 채팅 로그 라벨링**(§2-③ 루프와 연결).

**결과 (본실험 · KcELECTRA 파인튜닝 고정 · 2026-07-03 실행)**:

| 조합 | 작성체 F1 | 채팅체 F1 | 판정 |
|---|---|---|---|
| base (58,234) | 0.7096 | 0.4793 | 기준선 |
| **+voice (+36,677)** | 0.7056 (−0.004, 노이즈 범위) | **0.7358 (+0.257)** | ✅ **채택 후보** — 채팅체 우세, 평가셋 증량 후 확정 |
| +wellness (+1,002) | 0.7120 | 0.4395 (−0.040) | ❌ 기각 — 사전 가설(존댓말 42.8%·기쁨 12건) 적중 |
| +KOTE | 0.7111 | 0.4984 (+0.019) | ✅ 채택 후보 |
| +voice+KOTE | 0.6991 | **0.7801 (+0.301)** | 채택분 결합 — 결승 진출 |

**결승 (채팅체 150문장 확정 평가 · 누수 필터 적용 · 최종)**:

| 후보 | 작성체 F1 | **채팅체 150 F1** | 결과 |
|---|---|---|---|
| +voice | 0.7056 | 0.7431 | — |
| **+voice+KOTE** | 0.6994 | **0.8165** | 🏆 **최종 채택** — 배포 모델 (`kcelectra_emo4_ft_voiceKOTE`) |

- 150문장 클래스별(채택 모델): 기쁨 0.974(재현율 1.00) · 일반 0.827 · 분노 0.779 · 슬픔 0.686
- **최종 성과 요약**: 실사용형(채팅체) Macro F1 **0.48 → 0.82** (배포본 대비 작성체도 0.67 → 0.70)
- **누수 검사 기록**: aug_voice와 작성체 테스트 중복 3건(0.03%, 영향 미미)·채팅체와 0건 → 최종 학습에서 시험지 문장 전체 필터링 적용

- **핵심 발견**: 음성 전사(짧은 구어 발화)가 실사용형(채팅체) 성능을 0.48→0.74로 견인 —
  "작성체 지표가 낮아도 실사용에서 나을 수 있다"는 가설이 데이터 추가 차원에서 입증됨.
- 재현성: 세션 재시작 후 재실행에서 소수점 4자리까지 동일 (seed 고정).
