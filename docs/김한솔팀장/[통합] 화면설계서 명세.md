# 🖥️ [통합] 화면설계서 명세 (UI Specification)

> [!info] 문서 개요
> *   **본 문서의 목적**: 프로젝트 내 개별 화면 명세서(HTML Mockup 소스 포함)와 와이어프레임 가이드를 하나로 통합한 마스터 화면설계서 명세서입니다.
> *   **디자인 테마**: **사이월드 미니홈피 메타포 + 다이어리 꾸미기(다꾸) 감성**. 2.5px 검은 잉크 외곽선과 harmonious HSL 파스텔톤 컬러(세이지, 피치, Butter)를 사용하여 따뜻하고 편안한 다이어리 느낌을 연출합니다.
> *   **포맷 양식**: `화면설계서.pdf` 5쪽의 표준 양식을 준수하여 각 화면마다 **[메타데이터 헤더 표]**, **[와이어프레임(숫자 배지 ①, ② 표시)]**, **[기능 정의서(No-구성요소-설명 표)]**, **[체크포인트]** 구조로 정리되었습니다.
> *   **반응형 정책**: 데스크톱 웹 화면 우선으로 멀티 컬럼 레이아웃을 제공하되, 모바일 기기 접속 시 1열 카드 스택 레이아웃으로 유연하게 반응형 전환을 처리합니다.

> [!check] Check Point / 상태·분기 규칙
> - **턴 게이팅**: 대화 진입 시에는 일상 대화로 유연하게 시작하고, 고민 감지 시 감정 분석 및 6대 척도 추정 자동 활성화
> - **과의존 가드레일**: 연속 1.5시간 또는 50턴 도달 시 캐릭터 자발적 휴식 권유 배너 작동
> - **시크릿챗**: 토글 ON 시 대화 중 차/BGM 추천 카드는 정상 작동 및 렌더링되나, 세션 종료 즉시 백엔드 대화·분석 기록이 영구 파기(DELETE API 호출)되며 일일 마음 리포트는 미생성되고 홈 리다이렉트 (REQ-F-012)
> - **토큰 제약**: 최근 10턴 슬라이딩 윈도우, 캐릭터 응답 max_tokens=250 (REQ-NF-007)
> - **이모티콘**: 웰니스 메이트 전용 이미지 이모티콘 사용, 텍스트 유니코드 이모지 금지

## 5. UI 정책 및 규칙 (UI Rules & Policies)

1.  **점수 및 병명 배제 규칙**:
    *   사용자의 정신건강 데이터(PHQ-9 우울 척도, GAD-7 불안 척도 등)의 날것 점수(예: "우울증 23점 고위험군") 및 병명(조현병, 주요우울장애 등)을 사용자가 인지하는 화면 전반에 직접 노출하는 것을 엄격히 금지함. 대신 "안개가 짙게 낀 마음 상태", "마스킹 테이프로 칭칭 감은 긴장감"과 같은 은유와 위로 텍스트로 치환하여 표출할 것.
2.  **과의존(파라소셜) 방지 인터페이스**:
    *   대화 연속 시간이 1.5시간을 초과하거나 연속 대화 턴 수가 50턴에 도달할 경우, 화면 하단에 캐릭터가 "오늘 대화는 여기까지 하고 따뜻한 차 한 잔 마시며 스트레칭을 해볼까요?"라고 현실 활동을 권유하는 휴식 넛지 배너를 자동으로 활성화함. (재방문을 유도하되 중독적 체류시간은 인위적 가드레일 작동)
3.  **반응형 레이아웃 대응**:
    *   **데스크톱 웹**: 좌측 패널(캐릭터 및 모드 제어), 우측 채팅창의 2열(Multi-Column) 화면 구성.
    *   **모바일 기기**: 좌측 패널이 햄버거 메뉴 또는 하단 탭바로 격하되며, 화면 중앙에는 채팅창만 1열 스택 형태로 노출.
