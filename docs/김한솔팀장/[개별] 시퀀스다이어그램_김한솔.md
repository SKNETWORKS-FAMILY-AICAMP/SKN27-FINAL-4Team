## 시나리오 1. 일반 대화 플로우 (SCR-003)

```mermaid
sequenceDiagram
    actor User as 사용자
    participant FE as Frontend (SCR-003)
    participant ChatAPI as Chat API Server
    participant KcEL as KcELECTRA 감정분석
    participant LTM as Neo4j LTM
    participant RAG as RAG 지식노드
    participant GPT as GPT API
    participant DB as PostgreSQL

    User->>FE: 대화방 진입
    FE->>ChatAPI: GET /session/start (user_id, character_id)
    ChatAPI->>LTM: 직전 세션 메모리 조회
    LTM-->>ChatAPI: 메모리 키워드 반환 (없으면 날씨·운세 API 호출)
    ChatAPI-->>FE: opener 발화 생성 (콜드 스타트 방지)
    FE-->>User: 캐릭터 opener 배너 표시

    Note over User,FE: 1~3턴 구간 — 감정분석 유예
    User->>FE: 발화 입력 (turn 1~3)
    FE->>ChatAPI: POST /message (content, turn_count)
    ChatAPI->>RAG: 같이 찾아주는 질문 노드 조회
    RAG-->>ChatAPI: 동반 질문 템플릿
    ChatAPI->>GPT: 페르소나 프롬프트 + 동반 질문 합성
    GPT-->>ChatAPI: 캐릭터 응답 (max_tokens=250)
    ChatAPI-->>FE: 응답 반환 + 이미지 이모티콘 분기 정보
    FE-->>User: 캐릭터 말풍선 + 이미지 이모티콘 표시

    Note over User,DB: 4턴~ — 감정분석 + 척도 추정 활성화
    User->>FE: 발화 입력 (turn >= 4)
    FE->>ChatAPI: POST /message (content, turn_count=4+)
    ChatAPI->>KcEL: 감정 분류 요청 (비동기)
    KcEL-->>ChatAPI: emotion_code + confidence (p95 < 300ms)
    ChatAPI->>DB: SCALE_SCORE 세션 벡터 업데이트 (비동기)
    ChatAPI->>RAG: 감정 코드 기반 공감 노드 조회
    RAG-->>ChatAPI: 4대 공감 분기 템플릿 (응원/속상/화남/계획)
    ChatAPI->>GPT: 공감 분기 + 페르소나 프롬프트 합성
    GPT-->>ChatAPI: 캐릭터 응답 (max_tokens=250)
    ChatAPI-->>FE: 응답 + 공감분기 + 이모티콘 정보 + 차 추천 카드
    FE-->>User: 말풍선 + 이미지 이모티콘 + 차 추천 카드 + BGM 링크 표시

    User->>FE: 세션 종료 또는 이탈
    FE->>ChatAPI: POST /session/end
    ChatAPI->>DB: SCALE_SCORE 최종 확정 + CHAT_SESSION 종료
    ChatAPI->>LTM: 핵심 키워드 LTM 노드 업데이트
    ChatAPI-->>FE: 마음 리포트 생성 트리거
```

## 시나리오 2. 이너 카운슬 플로우 (SCR-004)

```mermaid
sequenceDiagram
    actor User as 사용자
    participant FE as Frontend (SCR-004)
    participant Orch as LangGraph Orchestrator
    participant Haeon as 해온 Agent (내러티브)
    participant Geulung as 그릉 Agent (CBT)
    participant Dalkong as 달콩 Agent (ACT)
    participant DB as PostgreSQL

    User->>FE: 이너 카운슬 버튼 클릭 (수동 발동)
    FE->>Orch: POST /inner-council/start (session_id, context)
    Orch->>DB: INNER_COUNCIL_SESSION 생성

    Note over Orch,Dalkong: LangGraph 턴 제어 시작 (최대 3턴 / 1,200토큰 상한)

    Orch->>Haeon: 사용자 고민 컨텍스트 전달
    Haeon-->>Orch: 위로·외재화 발화 (max_tokens=150)
    Orch->>DB: AGENT_TURN 기록 (turn_index=1)
    Orch-->>FE: 해온 발화 스트리밍
    FE-->>User: 해온 말풍선 + 이미지 이모티콘 표시

    Orch->>Geulung: 해온 발화 + 컨텍스트 전달
    Geulung-->>Orch: 직면·인지재구성 발화 (max_tokens=150)
    Orch->>DB: AGENT_TURN 기록 (turn_index=2)
    Orch-->>FE: 그릉 발화 스트리밍
    FE-->>User: 그릉 말풍선 + 이미지 이모티콘 표시

    Orch->>Dalkong: 이전 발화 + 컨텍스트 전달
    Dalkong-->>Orch: 코치·행동미션 발화 (max_tokens=150)
    Orch->>DB: AGENT_TURN 기록 (turn_index=3)
    Orch-->>FE: 달콩 발화 스트리밍
    FE-->>User: 달콩 말풍선 + 이미지 이모티콘 표시

    alt 사용자 개입
        User->>FE: 나도 한마디 입력
        FE->>Orch: POST /inner-council/intervene (user_input)
        Orch->>Orch: LangGraph Context에 사용자 입력 주입
        Note over Orch: 다음 에이전트 발화 방향 동적 반영
    end

    Orch->>Orch: 토큰 합산 확인 (1,200 초과 or 3턴 완료)
    Orch->>DB: 합의 요약 카드 생성 + INNER_COUNCIL_SESSION 종료
    Orch-->>FE: 합의된 위로 요약 카드 반환
    FE-->>User: 요약 카드 표시 + SCR-003 복귀
    DB->>DB: 요약 데이터 → 마음 리포트 + LTM 반영
```

## 시나리오 3. 위기 감지 분기

```mermaid
sequenceDiagram
    actor User as 사용자
    participant FE as Frontend
    participant ChatAPI as Chat API Server
    participant Crisis as 위기 분류기 (전용 LLM)
    participant GPT as GPT API

    User->>FE: 위기 신호 발화 입력
    FE->>ChatAPI: POST /message (content)
    ChatAPI->>Crisis: 위기 판정 요청 (페르소나 모델과 분리된 전용 LLM)
    Crisis-->>ChatAPI: 위해 의도 판정 (Recall >= 0.9 / FPR <= 10%)

    alt 위해 의도 판정됨
        ChatAPI->>GPT: 위로 집중 프롬프트 (외부 연락처·화면변화 금지)
        GPT-->>ChatAPI: 캐릭터 위로·공감 발화만 생성
        ChatAPI-->>FE: 위로 발화 반환 (화면 변화 없음, 외부 연락처 없음)
        FE-->>User: 캐릭터 위로 말풍선만 표시
        Note over FE,User: 화면 전환 없음 / 외부 연락처 제시 없음 / 오직 위로 발화
    else 일반 대화 판정
        ChatAPI->>GPT: 일반 공감 프롬프트
        GPT-->>ChatAPI: 일반 응답
        ChatAPI-->>FE: 일반 응답 반환
    end
```

## 시나리오 4. 시크릿챗 분기

```mermaid
sequenceDiagram
    actor User as 사용자
    participant FE as Frontend
    participant ChatAPI as Chat API Server
    participant DB as PostgreSQL
    participant Crisis as 위기 분류기 (익명)

    User->>FE: 시크릿챗 토글 ON
    FE-->>User: 비저장 세션 경고 알림 표시
    FE->>ChatAPI: POST /session/start (is_secret=true)
    ChatAPI-->>FE: 시크릿 세션 ID 발급 (메모리 전용)

    Note over ChatAPI,DB: is_secret=TRUE — DB 영구 저장 차단

    loop 대화 진행 중
        User->>FE: 발화 입력
        FE->>ChatAPI: POST /message (is_secret=true)
        ChatAPI->>Crisis: 위기 탐지 (익명, 세션 ID 없이)
        ChatAPI->>ChatAPI: 응답 생성 (메모리 내에서만 처리)
        ChatAPI-->>FE: 응답 반환
        Note over DB: DB 저장 없음 (MESSAGE, EMOTION_ANALYSIS, SCALE_SCORE 미기록)
    end

    User->>FE: 세션 종료 또는 탭 닫기
    FE->>ChatAPI: POST /session/end (is_secret=true)
    ChatAPI->>ChatAPI: 서버 메모리 즉시 파기
    Note over ChatAPI: 마음 리포트 생성 안 함 / LTM 업데이트 안 함
    ChatAPI-->>FE: 홈 화면 리다이렉트
    FE-->>User: SCR-002 홈으로 이동
```
