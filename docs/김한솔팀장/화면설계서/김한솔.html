전송 ➤
Description
  1. ① 글로벌 내비게이션 — 로고 + 홈·대화·마음 리포트·마이페이지·설정 탭
  2. ② 대표 캐릭터 영역 — 큰 일러스트 + 표정 4분기, 진입 시 메모리 있으면 안부·없으면 운세/날씨 opener
  3. ③ 차·BGM 추천 버튼 — 사용자가 직접 눌러 정서 매핑 힐링 차 / 유튜브 BGM 추천을 요청 (4대 공감 출력 시 자동으로도 카드 표시). 차 추천 시 카페인·알레르기 필터를 거침
  4. ④ 친밀도·세션 컨트롤 — 친밀도 게이지(톤 변화), 시크릿챗 토글, 이너 카운슬 시작
  5. ⑤ 대화 스레드 (공감 4모드) — 4턴 이후 감정분석 결과로 응원·속상·화남·계획 중 하나로 자동 분기, 모드마다 표정·말투·행동이 달라짐. 1~3턴은 '같이 찾아주는 질문', 위기 시 외부연결 없이 위로만
  6. ⑥ 추천 질문 — 입력 전에 탭할 수 있는 상황별 추천 질문 3개. RAG가 대화 맥락에 따라 갱신 (상황 칩 대신)
  7. ⑦ 입력바 — 최대 300자, STT 마이크, 계획 모드(웹검색), 전송
공감 4모드 (자동 분기)
  • 응원 — 잘하고 있다고 힘 실어주기
  • 속상 — 같이 속상해하며 경청
  • 화남 — 사용자 대신 화내주기 (대리 분노)
  • 계획 — 같이 해결책·다음 행동 짜기 (CBT)
Check Point
  • 턴 게이팅: 1~3턴 유예 / 4턴~ 분석·6척도
  • 공감 모드는 사용자가 고르는 게 아니라 감정분석으로 자동 결정
  • 토큰: 10턴 윈도우, max_tokens 250

  1. ① 이너 카운슬 헤더 — '이너 카운슬 시작' 버튼을 수동 클릭할 때만 오버레이 시작 (자동 발동 없음)
