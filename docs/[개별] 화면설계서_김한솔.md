> [!check] Check Point / 상태·분기 규칙
> - **턴 게이팅**: 1~3턴 감정분석 미기동 → 4턴부터 KcELECTRA + 6대 척도 추정 활성화 (REQ-F-002, 004)
> - **위기 대응**: 전용 위기 분류기 위해 판정 시 — 화면 전환·외부 연락처 없이 위로 발화만 출력 (REQ-F-010, 013)
> - **과의존 가드레일**: 연속 1.5시간 또는 50턴 도달 시 캐릭터 자발적 휴식 권유 배너 작동
> - **시크릿챗**: 토글 ON 시 세션 종료 즉시 대화·분석 파기, 카드·리포트 미생성, 홈 리다이렉트 (REQ-F-012)
> - **토큰 제약**: 최근 10턴 슬라이딩 윈도우, 캐릭터 응답 max_tokens=250 (REQ-NF-007)
> - **이모티콘**: 캐릭터별 전용 이미지 이모티콘 사용, 텍스트 유니코드 이모지 금지
