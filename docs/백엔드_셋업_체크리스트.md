# 백엔드 셋업 체크리스트 (팀 공용)

작성: 김한솔, 2026-07-13 — dev 받은 후 이 순서 그대로. 막히면 `python manage.py setup_check`부터.

## 0. 원칙

- **도커는 DB만, 장고는 로컬.** `docker compose up -d db neo4j` — `web`(wellness_django)은 배포용이라 로컬에선 띄우지 말 것 (포트 충돌 + 옛 코드가 응답을 가로챔)
- venv는 **app\.venv** (루트 .venv 아님)

## 1. 순서

```powershell
# ① DB 컨테이너 (web 제외!)
docker compose up -d db neo4j

# ② venv + 패키지
cd app\backend
..\..\app\.venv\Scripts\Activate.ps1
uv pip install -r requirements.txt     # 최초엔 임베딩 모델 등 다운로드로 몇 분

# ③ .env — 아래 키가 전부 있어야 함 (값은 팀 채팅 템플릿)
#    OPENAI_API_KEY / PG_* / NEO4J_URI=bolt://localhost:7687 / NEO4J_USER / NEO4J_PASSWORD

# ④ 마이그레이션 + 자가진단
python manage.py migrate
python manage.py setup_check           # 7항목 전부 ✓ 여야 정상

# ⑤ 서버
python manage.py runserver             # 시작 로그에 "[graph_memory] Neo4j 연결됨" 확인
```

## 2. 동작 확인 (1분)

1. **로그인** 후 채팅: `"나 다음 주 금요일에 제주도 여행 가"`
2. 5초 뒤 Neo4j Browser(localhost:7474)에서:
   ```cypher
   MATCH (u:User)-[:HAS_EVENT]->(e:Event) RETURN e.name, e.date
   ```
   → 제주도 여행이 보이면 기억 파이프라인 완주
3. 새 세션 열고 `"나 뭐 간다고 했었지?"` → 제주도를 답하면 회상까지 정상

## 3. 자주 부러지는 곳

| 증상 | 원인 | 조치 |
|---|---|---|
| 챗봇은 되는데 기억이 안 쌓임 | 비로그인 (게스트는 설계상 무저장) | 로그인 후 테스트 |
| 〃 | wellness_django 컨테이너가 응답 중 | `docker stop wellness_django` → 로컬 runserver |
| 〃 | .env에 NEO4J_* 없음 (조용히 비활성) | .env 3줄 추가 → 서버 재시작 |
| `type "vector" does not exist` | 옛 postgres 이미지 | `docker compose pull db` 후 재기동 (pgvector/pgvector:pg15) |
| 의미 검색이 안 먹는 느낌 | sentence-transformers 미설치 (키워드 폴백으로 동작) | `uv pip install -r requirements.txt` |
| `No module named django` | 루트 .venv 활성화함 | **app\.venv** 활성화 |

## 4. 안 해도 되는 것

- `memory_vector_init` — 벡터 인덱스는 서버 첫 기동 때 자동 생성됨. 이 명령은 "임베딩 도입 전 데이터가 있는 개발 DB" 백필 전용
- Neo4j 설치 — 도커가 함. 계정 만들기도 불필요 (compose 환경변수로 자동)
