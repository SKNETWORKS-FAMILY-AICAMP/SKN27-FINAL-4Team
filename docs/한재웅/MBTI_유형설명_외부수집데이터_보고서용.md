# MBTI 유형 설명 외부 수집 데이터

## 1. 수집 목적

본 데이터는 월간 MBTI 성향 분석 결과를 사용자에게 설명하기 위한 외부 참조 지식 데이터이다. 내부 사용자 답변의 점수, 축별 선택값, 월간 MBTI 산출값을 바꾸는 데이터가 아니라, 이미 산출된 `estimated_mbti_type`을 리포트 문장으로 자연스럽게 설명하기 위한 보조 데이터로 사용한다.

사용 위치는 `mbti_monthly_reports.report_sections_json`의 "현재 MBTI 성격 유형 간단 설명" 섹션이다. MVP+ 단계에서 Graph RAG를 적용할 경우, 이 데이터를 검색 가능한 참조 문서로 색인하여 유형별 설명 후보를 가져오는 용도로 사용할 수 있다.

## 4. 데이터 필드 정의

| 필드명 | 데이터 타입 | 설명 | 예시 |
| --- | --- | --- | --- |
| `mbti_type` | string | 4글자 MBTI 유형 코드 | INTP |
| `axis_group` | string | 유형을 구성하는 주요 선호 조합 그룹 | NT 사고-직관형 |
| `summary_for_report` | text | 리포트에 바로 사용할 수 있는 짧은 한국어 설명 | 아이디어의 원리와 구조를 깊게 탐색하는 경향이 있습니다. |
| `report_keywords` | array[string] | 리포트 문장 생성용 핵심 키워드 | ["분석", "논리", "탐구"] |
| `strength_context` | text | 긍정적으로 설명할 때 사용할 맥락 | 복잡한 문제를 원리 중심으로 정리하는 데 강점 |
| `caution_context` | text | 단정적 표현을 피하기 위한 주의 맥락 | 대인관계 성향이나 실제 행동을 단정하지 않음 |
| `recommended_sentence` | text | 마이페이지 리포트 예시 문장 | 이번 달에는 INTP에 가까운 경향이 관찰됩니다. |
| `source_basis` | string | 재가공 근거 출처 | MBTI 공식 유형 설명 및 4개 선호 쌍 설명 기반 재작성 |

## 6. 보고서 작성용 문장

본 프로젝트에서 수집한 MBTI 유형 설명 데이터는 16개 MBTI 유형의 일반적 특징을 외부 공개 자료를 참고해 자체적으로 재작성한 참조 데이터이다. 이 데이터는 사용자의 MBTI를 직접 판정하는 원천 데이터가 아니라, 내부 분석 파이프라인에서 산출한 `estimated_mbti_type`을 사용자가 이해할 수 있도록 설명하는 보조 지식으로 사용된다. 따라서 점수 계산, 축별 `selected_letter`, 월간 MBTI 조합 결과에는 영향을 주지 않으며, 리포트 문장 생성과 Graph RAG 기반 설명 보강에만 활용한다.

## 7. 법적·윤리적 검토

- MBTI 및 Myers-Briggs 관련 명칭은 상표권이 있는 표현이므로 공식 검사처럼 홍보하거나 진단 결과처럼 표현하지 않는다.
- 유형 설명은 공개 자료의 원문을 복제하거나 번역하지 않고, 서비스 리포트 목적에 맞게 짧은 한국어 설명으로 재작성한다.
- 사용자의 성격을 단정하지 않고 "이번 달 답변에서 관찰된 경향", "가까운 경향"처럼 보조 분석 문구를 사용한다.
- 본 데이터는 개인 식별 정보가 없는 외부 참조 데이터이지만, 내부 사용자 답변과 결합되어 리포트가 생성되므로 최종 리포트는 내부 서비스 화면에서만 제공한다.
