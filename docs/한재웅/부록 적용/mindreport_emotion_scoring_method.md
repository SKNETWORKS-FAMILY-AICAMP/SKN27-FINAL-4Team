# 마음리포트 감정 점수 산정 규칙

## 사용 목적

이 점수는 사용자의 자유 대화에서 날짜별 감정 흐름을 비교하기 위한 비진단적 내부 지표다.
질환 진단, 위험도 판정, 치료 효과 평가 또는 검증된 환자보고결과(PRO) 점수로 사용하지 않는다.

자유 대화를 임상 점수로 직접 변환하는 공인 표준은 없다. 따라서 검증된 감정 이론에서
차원의 구조만 참고하고, 마음리포트의 환산식과 데이터 충족 기준은 제품 규칙으로 명시한다.


## 생성 데이터 기준

- 주간 리포트: 해당 주의 사용자 발화 5개 이상
- 월간 리포트: 해당 월의 사용자 발화 20개 이상
- 사용자 발화만 포함하며 AI 응답은 제외한다.
- 5개와 20개는 기존 마음리포트의 운영 기준이며 임상적으로 검증된 절단값이 아니다.
- 상승·하락·변동 시계열 판정은 서로 다른 날짜의 점수가 3개 이상일 때만 수행한다.
- 3일 기준은 단일·이중 관측으로 추세를 단정하지 않기 위한 보수적 제품 안전장치다.

## KcELECTRA의 역할

운영 기본 경로는 파인튜닝된 KcELECTRA가 각 사용자 발화를 다음 네 감정의 확률로 분류한다.

| 감정 | 일별 점수 가중치 |
| --- | ---: |
| 기쁨 | 100 |
| 일반 | 50 |
| 슬픔 | 25 |
| 분노 | 0 |

같은 날짜의 발화별 확률을 평균하여 일별 확률을 만들고, 가장 높은 평균 확률의 감정을
대표 감정 라벨로 보존한다. 대표 라벨은 설명용 분류이고, 긍정·중립·부정 상태는 아래 최종
점수에서 별도로 파생한다. 따라서 혼합 감정이 많은 날에는 대표 라벨과 점수 상태가 다를 수
있다.

## 서버 점수 계산

```text
일별 감정 점수 = 기쁨확률*100 + 일반확률*50 + 슬픔확률*25 + 분노확률*0
최종 범위 = 0~100
```

- 55점 초과는 `positive`, 45점 미만은 `negative`, 그 사이는 `neutral`로 정규화한다.
- 대표 감정 라벨보다 점수에서 파생한 상태를 시계열 및 화면 아이콘의 기준으로 사용한다.
- 이 가중치는 임상 척도가 아니라 날짜 간 변화를 비교하기 위한 제품 규칙이다.
- 명시적으로 주입한 테스트 클라이언트는 이전 affect 차원 형식을 사용할 수 있지만, 운영
  기본 경로와 저장되는 `scoring_route`는 `kcelectra_scoring`이다.

## 시계열 규칙

- 최소 3개 날짜 미만: 흐름 근거 부족
- 상승: 전반부 대비 후반부 평균 +8점 이상 또는 첫날 대비 마지막 날 +12점 이상
- 하락: 전반부 대비 후반부 평균 -8점 이하 또는 첫날 대비 마지막 날 -12점 이하
- 변동: 표준편차 16 이상이면서 유의한 방향 전환 1회 이상이거나, 18점 이상 상승과 하락이
  각각 1회 이상 함께 발생
- 그 외: 유지

같은 방향의 큰 점프가 반복되는 경우에는 변동성보다 순방향 상승·하락을 우선한다.

시계열 수치는 현재 제품 규칙이며 실제 사용자 데이터와 사람 평가자 기준으로 별도 보정해야
한다. 배포 후에는 익명화된 검증 세트에서 평가자 간 일치도, LLM 재검사 일치도, 오탐·미탐을
측정하고 버전별로 임계값을 고정한다.
