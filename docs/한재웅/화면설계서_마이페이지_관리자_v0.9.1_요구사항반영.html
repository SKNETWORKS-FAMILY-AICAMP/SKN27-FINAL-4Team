UI Specification

마이페이지와 관리자 페이지 분리형 HTML 화면설계서

제공된 요구사항 정의서의 추가설명을 기준으로 마이페이지 메인, 기능 팝업, 일반 사이트형 설정 화면, 관리자 콘솔을 분리 설계했다. 기존 화면설계서 PDF의 원칙에 맞춰 와이어프레임, 디스크립션, 수정 이력, 메뉴 트리, 스크린 리스트, 플로우, 정책, 권한, 검증 항목을 함께 포함한다.

v1.0 2026-06-18 HTML Prototype
1. 와이어프레임

마이룸, 설정, 관리자 콘솔의 화면 배치와 주요 인터랙션 영역을 시각화한다.

2. 디스크립션

각 화면의 버튼, 탭, 필터, 정책 안내, 오류 상태를 구현 단위로 설명한다.

3. 정책/권한

시크릿챗 비저장, 비의료 문구, 관리자 RBAC, 개인정보 마스킹을 명시한다.

4. 검증

팝업 접근성, 설정 즉시 반영, 관리자 감사 로그 등 QA 기준을 추적한다.

마이룸 정책

  • 기능 아티팩트는 붉은 점, 라벨, 포커스 윤곽선으로 구분한다.
  • 모든 분석 문구는 자기이해, 감정 인식, 생활 제안 중심으로 작성한다.
  • 진단명, 질병명, 위험 등급, 임상 점수처럼 의료적 오해를 줄 표현은 노출하지 않는다.
  • 시크릿챗은 저장되지 않으며, 일반챗 전환 시 저장 범위와 반영 시점을 재확인한다.

설정 디스크립션

  • 저장 성공 시 상단 토스트로 “변경사항이 반영되었습니다”를 표시한다.
  • 저장 실패, 네트워크 오류, 권한 오류는 원인과 재시도 버튼을 함께 제공한다.
  • 설정 변경은 현재 화면과 관련 기능에 즉시 반영되어야 한다.
  • 계정 삭제는 삭제 범위 확인, 최종 확인, 완료 화면의 3단계로 구성한다.
