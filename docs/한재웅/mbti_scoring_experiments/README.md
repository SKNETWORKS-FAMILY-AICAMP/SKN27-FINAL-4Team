# MBTI 응답 점수화 안정성 실험

이 폴더는 월간 MBTI 분석의 응답별 점수화 방식을 비교하기 위한 실험 설계 문서다.
운영 파이프라인을 바로 수정하지 않고, 후보 방식을 같은 샘플과 같은 평가 기준으로 비교한 뒤 가장 안정적인 방식을 선택한다.

## 실험 후보

| 코드 | 방식 | 요약 |
| --- | --- | --- |
| `persona_direct` | 페르소나 기반 직접 채점 | 기존 프롬프트처럼 MBTI 분석가 페르소나가 `-1.0~+1.0` 점수를 직접 산정한다. |
| `rubric_code` | 루브릭코드 기반 채점 | LLM은 점수가 아니라 루브릭코드를 고르고, 서버가 코드별 고정 점수로 변환한다. |
| `triple_majority` | 3자 LLM 다수결 | 3개 LLM이 기존 점수 체계로 채점하고, 2개 이상 일치한 값을 최종 점수로 쓴다. |
| `hundred_point_ensemble` | 100점제 앙상블 구간 다수결 | 3개 LLM의 100점 점수를 5개 구간으로 바꾼 뒤 구간 다수결과 정규화 평균을 적용한다. |
| `triple_supervisor` | 3자 LLM 슈퍼바이저 | 3개 LLM의 판단과 근거를 보고 규칙 기반 슈퍼바이저가 최종 점수를 정한다. |

## 공통 입력

모든 실험은 같은 입력을 사용한다.

```text
case_id
axis
question
answer
human_score
human_status
```

`axis`는 `IE`, `SN`, `TF`, `JP` 중 하나다. `human_score`는 사람이 사전에 정한 기준 라벨이며, `human_status=coded`일 때만 숫자 점수를 가진다.

## 공통 출력

각 방식은 최종적으로 아래 형태의 결과를 만든다.

```text
case_id
strategy
predicted_score
predicted_status
reason
raw_output
```

운영 DB 스키마에 바로 넣기 위한 파일이 아니라, 실험 비교를 위한 중간 산출물이다.

## 평가 기준

| 지표 | 의미 |
| --- | --- |
| 완전 일치율 | 사람 라벨과 모델 점수가 정확히 같은 비율 |
| 인접 일치율 | 사람 라벨과 모델 점수가 한 단계 이내로 가까운 비율 |
| null 비율 | `insufficient_context` 또는 `failed`로 빠진 비율 |
| 과잉 확신률 | 사람 라벨이 약한 성향/중립인데 모델이 `+1.0` 또는 `-1.0`을 준 비율 |
| 평균 절대 오차 | coded 케이스에서 사람 점수와 모델 점수의 평균 차이 |

## 실행 위치

실험 코드는 운영 코드와 분리해 아래 위치에서 수동 실행한다.

```text
test/jaewung/mbti_scoring_experiments/
```

현재 생성된 코드는 실제 LLM 호출을 하지 않는 실험 골격이다. 이후 각 후보 방식의 LLM 호출부를 전략별로 채워 넣고, 결과 CSV를 비교한다.
