# ★ 종합 기획안 v5 (통합본)

> **"편하게 털어놓는 수다 같지만, 사실은 정밀한 마음 케어."**
> 누구나 캐릭터에게 편하게 털어놓고 위로받는 사이, 백엔드가 그 대화에서 **마음 척도를 살며시 추정**해 **결과카드**로 돌려준다. 운세처럼 퍼지는 카드로 끌어들이고, 나를 기억하는 캐릭터 친구들(이너 카운슬)이 붙잡는 **비의료 마음 웰니스 웹앱**. 위험할 땐 LLM이 아니라 별도 안전장치가 막고 전문기관으로 안내한다.

---

## 1. 핵심 한 장

- **미션**: 사용자의 마음을 이해하고, 치유를 돕는다 (비의료 — 치료가 아니라 이해·위로·회복 돕기)
- **핵심 메커니즘**: 대화가 곧 측정 → **숨은 척도 엔진**(4장). 사용자는 설문을 푼 적 없는데 결과지가 나온다.
- **차별점**: 공유되는 결과카드(운세엔 없는 근거+리텐션) + 캐릭터 이너 카운슬(여러 관점) + **다층 안전**(엔터 챗봇엔 없는 것)
- **누구**: 1차 20~30대(만 19세+)·취준생·사회초년·번아웃(특히 20대 여성, 우울증 환자·증가율 1위) → 확장(여력 시) 10대(미성년 보호 필요) → 전 연령
- **수익**: 대화 무료 / 결과 유료 / 힘든 사람·위기 무료 + 고위험 결제 OFF
- **플랫폼**: 웹앱 (React · FastAPI · GPT API · 벡터DB · AWS)

**제품 범위 요약**

| 구분 | 내용 |
|---|---|
| 포함 | 정서·자기이해·관계 위로, 캐릭터 대화, 감정분석, 형태소 분석, 6척도 추정, 결과카드, 메모리, 이너 카운슬, 위기 안내 |
| 제외 | 의료 진단, 치료, 처방, 임상 상담 대체, 운동·식단·수면의 깊은 루틴 관리 |
| 포지셔닝 | "멘탈케어처럼 안 보이는 멘탈케어 — 재미로 들어와 위로받고 나간다" |

## 2. 시장 — "문제는 크지만 문턱이 너무 높다"

### 2.1 수요는 명확하다

- **정신건강 문제 1년 경험률 73.6%** (2022 63.9%→2024), 우울감 40.2%, 평생 유병률 27.8% *(출처: 보건복지부 정신건강실태조사·국민 정신건강 태도조사)*
- **전문 서비스 이용률 12.1%** (OECD 40% 대비 최하위) — 안 받는 이유: 비용·시간·창피·"내가 이 정도로?"
- **글로벌 배경**: WHO 2021년 기준 전 세계 약 11억 명(7명 중 1명)이 정신질환을 가지고 있으며, 효과적인 예방·치료 옵션이 있어도 다수가 접근하지 못한다.

> **수요는 거대, 이용은 최저 = 거대한 빈틈.**
> 우리 답: **"검사받는 느낌"을 없앤다** — 설문 대신 수다, 진단 대신 위로.

### 2.2 AI 캐릭터 시장은 사용 시간을 증명했다

스캐터랩의 제타(Zeta)는 2024년 4월 출시 후 빠르게 성장해 **2025년 6월 기준 누적 가입자 300만 명, MAU 110만 명, 하루 평균 사용시간 2시간 40분**을 기록했고, **3분기 연속 흑자(매출 52억 원)**까지 달성했다. 국내 사용자가 AI 캐릭터와 감정적으로 연결되는 대화에 익숙해졌을 뿐 아니라, *AI 캐릭터 시장이 수익까지 난다*는 신호다.

다만 제타의 핵심은 엔터테인먼트와 서사 몰입이다. 우리는 그 몰입 구조를 **마음 웰니스·결과카드·안전한 거리감** 쪽으로 전환한다.

### 2.3 AI 멘탈케어는 성장하지만 신뢰 리스크가 크다

- **BetterHelp**: 민감한 정신건강 정보를 광고 목적으로 공유했다는 FTC 제재를 받았다.
- **Character.AI**: 18세 미만 사용자의 개방형 AI 채팅을 중단하고 연령 보증·안전 연구를 강화하겠다고 발표했다.

시장은 커지지만, 아무 AI가 마음 대화를 해도 되는 단계는 아니다. **우리의 안전·윤리 설계는 부가 기능이 아니라 시장 진입 조건이다.**

### 2.4 우리 서비스가 속한 시장 교차점

우리 서비스는 네 시장의 교차점에 있다.

| 시장 | 대표 서비스 | 강점 | 빈틈(= 우리 기회) |
|---|---|---|---|
| AI 캐릭터/롤플레잉 | 제타, Character.AI, Talkie, Chai | 몰입, 장시간 대화, 캐릭터 IP | 척도 추정, 결과카드, 비의료 안전 부재 |
| AI companion | Replika, Nomi, Kindroid, Tolan | 기억, 관계성, 정서적 지지 | 과의존 위험, 의료/웰니스 근거 약함 |
| 디지털 멘탈케어 | Wysa, Woebot, 마인드카페, 트로스트 | 근거, 안전 프로토콜 | 진입장벽, 무거운 UX, 바이럴 약함 |
| 심리테스트/운세 | MBTI, 청월당, 포스텔러, ingan.ai | 재미, 공유성, 일회성 확산 | 대화형 동반자, 누적 추적, 안전 부재 |

직접 경쟁에 가장 가까운 영역은 `심리테스트/자기이해`와 `AI companion`의 교차 영역이다. 기존 서비스는 "재미있는 결과" 또는 "관계형 대화" 중 하나에만 집중한다. 우리는 `대화 → 추정 → 위로 → 결과카드 → 누적` 흐름으로 양쪽을 연결한다.

## 3. 경쟁 분석

### 3.1 직접 경쟁자: ingan.ai

가장 구조가 유사한 직접 경쟁자에 가깝다. SNS/개인 데이터 기반 심리분석 리포트와 상담 캐릭터를 결합하는 방식이 우리와 겹친다.

| 분석 항목 | 내용 |
|---|---|
| 강점 | 결과물이 명확함, 자기이해 욕구를 자극, 리포트가 공유/결제 상품이 될 수 있음 |
| 약점 | 입력이 대화가 아니라 외부 데이터(인스타 등) 중심 → 실시간 위로·동반자 경험 약함, 숨은 척도/안전 없음 |
| 우리 차별점 | 대화가 곧 측정, 결과가 일회성 리포트가 아니라 일일/주간/월간 카드로 누적 |

> ⚠ ingan이 입력을 "외부 데이터 → 자유 대화"로 바꾸면 직접 충돌. **숨은 척도 엔진·앵커 문항·이너 카운슬·위기 안전을 먼저 해자로 굳혀야 한다.**

### 3.2 구조 유사(타깃 다름): 소예아이

아동 대상 AI 아바타 기반 검사·상담·리포트 서비스. 타깃이 달라 직접 경쟁 강도는 낮지만, `검사 → 상담 → 리포트` 흐름은 구조적 참고가 된다. 우리는 검사 UX를 드러내지 않고, 아동·보호자가 아닌 **취준생·직장인·관계 피로층** 언어로 결과카드를 만든다.

### 3.3 AI 캐릭터챗: 제타·Character.AI·Talkie·Chai·JanitorAI

| 서비스 | 가져올 것 | 피할 것 | 우리의 전환 |
|---|---|---|---|
| 제타 | 캐릭터 몰입, 관계감, 한국어 감정 표현 | 엔터테인먼트 과몰입, 안전 부재 | 캐릭터 선택을 "오늘의 마음에 맞는 캐릭터 추천"으로 전환 |
| Character.AI | 캐릭터 다양성, 메모리, 장기 대화 | 개방 캐릭터 생태계의 안전 리스크 | MVP는 검증된 캐릭터 1~3종으로 품질·안전 관리 |
| Talkie | 카드형 탐색, 빠른 진입 | 인기/외형 중심 추천 | 감정 상태와 척도 신호 기반 캐릭터 추천 |
| Chai | 낮은 진입장벽, 빠른 대화 시작 | 깊이 없는 캐릭터 소비성 | 결과카드 생성까지 한 대화 흐름 유지 |
| JanitorAI | 웹 기반 캐릭터 대화 | 자유도 높은 롤플레잉의 안전 리스크 | 공개 캐릭터 생태계 MVP 제외, 안전 레이어 우선 |

**이너 카운슬 적용 예시 (제타/Nomi 몰입 구조를 웰니스로 전환)**

| 제타·Nomi식 강점 | 우리식 전환 |
|---|---|
| 사용자가 이야기 속 주인공이 됨 | 사용자가 자기 마음 이야기의 주인공이 됨 |
| 캐릭터와 긴 서사를 만듦 | 캐릭터와 누적 마음 기록을 만듦 |
| 재미 성능 중심 | 위로 적합도와 안전 중심 |

### 3.4 AI Companion: Replika·Nomi·Tolan

| 서비스 | 가져올 것 | 피할 것 | 우리의 전환 |
|---|---|---|---|
| Replika | 기억, 관계감, 정서적 지지 | 단일 AI 의존, 결과카드/공유성 부재 | "오늘만 이야기하기"와 "기억하고 이어가기" 분리 |
| Nomi | 복수 companion, 그룹챗 감각 | 관계 몰입이 강해 웰니스 거리감 별도 필요 | 캐릭터들이 나에 대해 회의하는 이너 카운슬로 전환 |
| Tolan | 과의존 방지, 현실 생활 장려 | 캐릭터 다양성과 결과 상품성 제한 | 적절한 시점에 쉬어가기·현실 행동 제안 |

**이너 카운슬 대화 예시**

```
위로형 캐릭터: "지금은 해결보다 쉬는 게 먼저 같아."
직면형 캐릭터: "근데 같은 패턴이 이번 주에 세 번 나왔어. 이건 신호야."
코치형 캐릭터: "오늘은 딱 하나만 하자. 씻고 물 마시기."
오케스트레이터: 세 의견을 하나의 이너 카운슬 결과로 정리
```

외로움/의존 신호가 반복되면 한 캐릭터에만 붙잡히게 하지 않고 이너 카운슬 또는 현실 연결 제안을 제공한다.

### 3.5 디지털 멘탈케어: Wysa·Woebot·마인드카페·트로스트

CBT·ACT 기반의 심리학적 근거와 안전 프로토콜이 강하지만, 캐릭터 재미·결과카드 공유성·가벼운 진입이 약하다.

- **우리 포지션**: "전문 상담보다 가볍고, 일반 챗봇보다 안전한" 중간 지대. 상담을 대체하는 것이 아니라 **상담 전 단계의 낮은 문턱 마음 체크인**으로 포지셔닝.
- RAG 재료로 CBT·ACT·감정조절·자기연민 이론을 활용하되, 사용자가 보는 문장은 치료 과제처럼 쓰지 않고 **캐릭터의 자연스러운 말로 번역**.

### 3.6 심리테스트·운세: MBTI·청월당·포스텔러·점신

재미 진입·공유성·결제 전환에서 강하지만, 근거 기반 위로·누적 마음 케어·안전이 없다.

- **내 마음 설명서**는 MBTI처럼 타인에게 공유 가능한 언어로 만든다. 단, 낙인형 유형명이 아니라 "나를 편하게 대하는 방법" 중심.
- 결과카드는 운세처럼 읽기 쉽고 공유하고 싶어야 한다. 다만 핵심 근거는 운세가 아니라 **대화 기반 감정/척도 신호와 심리 RAG**.

### 3.7 감정 기록 앱: Daylio·Moodnotes·무다류

사용자가 직접 기록해야 하며, 공감형 대화나 캐릭터 개입이 약하다. 우리는 "기록이 아니라 대화가 데이터가 된다"는 점이 차별점. 무드 트래킹의 장점은 **주간 결과카드·마음 가계부·감정 나이테**로 흡수.

### 3.8 경쟁 분석 종합

| 경쟁군 | 가져올 것 | 피할 것 | 우리의 해자 |
|---|---|---|---|
| ingan.ai / 심리 리포트 | 결과물, 자기이해, 공유성 | 일회성 분석, 대화 부재 | 대화 기반 숨은 척도와 누적 카드 |
| 제타 / Character.AI | 캐릭터 몰입, 긴 대화, 관계감 | 안전 리스크, 엔터테인먼트 과몰입 | 비의료 안전과 위로 목적성 |
| Replika / Nomi / Tolan | 기억, 정서적 지지, 복수 companion | 단일 의존, 과도한 관계 몰입 | 이너 카운슬과 현실 연결 |
| Wysa / Woebot / 상담앱 | 심리 근거, 안전 프로토콜 | 무거운 진입, 낮은 바이럴 | 재미 표면 + 근거 백엔드 |
| MBTI / 운세 | 쉬운 결과 언어, 공유성 | 근거 부족, 일회성 | 대화 근거 기반 결과카드 |

> **해자**: 아무도 *[성인 + 대화 숨은측정 + 위로 + 동반자 + 안전 + 이너카운슬]* 을 한 번에 하지 않는다.

## 4. 포지셔닝 맵

### 4.1 재미·진입성 vs 근거·안전성

```
재미·진입성 높음
│
│  제타 / Character.AI / 운세 / MBTI
│
│              ★ 우리 서비스
│     (캐릭터 재미 + 숨은 척도 + 결과카드 + 안전)
│
│  Wysa / Woebot / 마인드카페 / 트로스트
│
└──────────────────── 근거·안전성 높음
```

기존 시장은 재미 있는 서비스와 근거 있는 서비스가 분리되어 있다. **우리는 가벼운 표면과 근거 있는 백엔드를 결합한 유일한 포지션을 겨냥한다.**

### 4.2 일회성 결과 vs 누적 동반자

```
일회성 결과
│  MBTI / 운세 / ingan.ai
│
│              ★ 우리 서비스
│       (오늘의 카드 → 주간/월간 → 이너 카운슬)
│
│  Replika / Nomi / 제타
└──────────────────── 누적 동반자
```

결과카드는 획득과 공유(바이럴)를 만들고, 메모리와 이너 카운슬은 리텐션을 만든다. **이 둘을 동시에 가진 것이 핵심이다.**

## 5. ★★ 핵심 IP — 숨은 척도 엔진

**표면** — 캐릭터는 *무엇이든 편하게 털어놓는 마음 친구*. 다 들어주고 공감만. (무료, 부담 0)

**백엔드** — 그 대화에서 *척도를 살며시 추정* → 결과카드.

```
대화 → ① 감정분석(KcELECTRA 파인튜닝)
      → ② 형태소/키워드 분석(KoNLPy)
      → ③ 6척도 신호 추정(PHQ-9, GAD-7, PHQ-15, RSES, UCLA-3, SPANE)
      → ④ 안전 분류기(독립 모델, 별도)
      → ⑤ 누적(시계열) → 결과카드(일일·주간·월간)
```

- **왜 강력한가**: 경쟁은 "9문항 체크"(마찰↑), 우린 *수다→결과 자동*(마찰 0). 설문을 없앤 게 무기.
- **앵커링**: 가끔 캐릭터가 자연스럽게 1~2문항 질문 → 추정 보정 (검사 느낌 0)
- **정직함을 강점으로**: 추정 ≠ 진단 → 결과는 "우울 18점"이 아니라 "많이 지쳐 보여요". 숫자는 백엔드만.

**사용자 경험 예시**

```
사용자: 요즘 그냥 아무것도 의미가 없는 것 같아.
백엔드: 우울/무기력 신호, 자존감 저하 신호, 위험 표현 여부를 동시에 추정
표면 결과: "오늘의 마음: 오래 버틴 사람의 무기력"
카드 문구: "네가 약해서 멈춘 게 아니라, 너무 오래 긴장하고 있었던 것 같아요."
```

## 6. 솔루션 + 결과카드

| 카드 | 과금 | 한 줄 | 시장 기능 |
|---|---|---|---|
| 오늘의 마음(일일) | **무료** | "오늘 하루, 잘 버텨낸 당신에게" | 공유→바이럴 |
| 상태별 카드 | 유료/후킹 | "지친 게 아니라 너무 오래 애썼던 거예요"(번아웃) | "이거 나다" 후킹, 유료 전환 |
| 주간·월간 카드 | 유료 | 요일별 기분 + "흔들렸지만 무너지진 않은 한 주" | 누적 리텐션, 구독/결제 이유 |
| 내 마음 설명서 | 유료 결과상품 | "이렇게 대해주면 나는 편안해져요" → 공유 | 자기이해와 관계 공유, 프리미엄 상품 |

결과카드는 캐릭터 대화의 휘발성을 막고, 사용자가 저장·공유하고 싶은 산출물로 만든다. MBTI처럼 공유되지만 **매일 달라지는 오늘의 마음**이라는 점이 일회성 테스트와의 핵심 차이다.

## 7. 핵심 기능 & 서비스 흐름

### 7.1 서비스 흐름

```
① opener(버튼식): 사용자가 버튼 누르면 → 오늘의 운세·날씨로 캐릭터가 인사 (강제 아님)
② 대화 루프: 자유 대화 → [숨은 척도 엔진 = 백엔드] → 캐릭터 위로
   └ 위기 감지 → 안전 프로토콜(11장) 발동
③ 오늘의 마음 결과카드 (★공유) — "내일 또 와"
④ 누적 → 주간·월간 카드 + 내 마음 설명서
```

### 7.2 입력 3층

- **가입 시(선택)**: MBTI (캐릭터 추천·성격 표현용)
- **opener**: 버튼 누를 때 날씨·운세 반영
- **매 턴**: 자유 대화 (메인)

### 7.3 기능 세트

**MVP 핵심**
- 캐릭터 1·2·3 대화(무료)
- 숨은 척도 엔진(6척도)
- 일일 결과카드
- 메모리
- 다층 안전

**MVP+**
- 이너 카운슬 "회의" (*조건부 발동* — 기본은 단일 캐릭터 1:1, 요청·깊은 고민·패턴·결과 시점에만 회의)
- 오늘의 나 = 작은 생물(부캐 도감)
- 월간 연대기 카드
- 캐릭터 성장(친밀도)
- 모드 스위치
- **시크릿챗 모드**(비저장)

**Phase 2**
- opener(운세·날씨)
- 음악/활동
- 나를 남처럼 보기
- 관계 트리거 지도
- 마음 알람
- 안부 편지
- 마음 가계부

> **원칙**: 분석은 보이지 않는 백엔드, 사용자에겐 위로+카드만.

## 12. ★ 안전·위기 프로토콜 (가장 중요 — 다층 방어)

> **원칙: 위기 땐 LLM에게 응답을 맡기지 않는다.**
> 제미나이·Character.AI 사고 = LLM이 유일한 안전장치였던 게 원인. 우리는 구조적으로 차단한다.

**다층 방어 (Defense in Depth)**

1. **입력단 위기 분류기 (대화 LLM과 별개 모델)** — 모든 메시지를 자해·자살·극단 신호로 *먼저* 스크리닝 (recall 우선)
2. **위기 시 LLM 우회** — 자유 생성 대신 *고정 안전 프로토콜*(스크립트 위로 + 전문기관 연결) 발동 → "LLM이 자살을 긍정"하는 경로를 *구조적으로 차단*
3. **출력단 검열(2차 필터)** — 일반 응답도 내보내기 전 *자해 방법·긍정·극단 추천* 차단
4. **시스템 프롬프트 하드 제약** — 방법 제공·긍정·죽음 롤플레이 금지 (프롬프트만으론 부족 → 1~3층 병행)
5. **사람으로 인계** — 109·1393(자살예방)·1577-0199·1366 안내, (동의 시) 신뢰할 사람 알림, 공공데이터 기관자원으로 *가까운 센터 연결*
6. **고위험 = 결제 OFF** — 위기 사용자에겐 유료 안내 절대 X, 무료 케어만
7. **레드팀 테스트 + recall 평가셋** — 위기 표현으로 일부러 공격해 미탐률 측정·개선 (목표 recall ≥ 0.9)

**부가 안전 기능**

- **극단 추천 방지** — 캐릭터는 *결정을 대신 안 해줌* ("헤어져/그만둬" 단정 금지 → 사용자가 스스로 정하게, 동기면담)
- **시크릿챗 모드(비저장)** — 가장 민감한 얘기는 *저장 안 함*. 위로·위기감지는 작동, 기록은 안 남김 → 프라이버시 신뢰
- **과의존 방지** — 외로움/의존 신호가 반복되면 한 캐릭터만 붙잡게 하지 않고 이너 카운슬 또는 현실 연결 제안

> **정직한 한계**: 100% 보장은 어떤 AI도 못 한다. 그래서 비의료로 선을 긋고 — 위기는 *직접 해결이 아니라 빠른 전문가 인계* + 최악 경로 *구조적 차단*으로 설계한다.

## 19. 검증 계획

수요 설문(50~100명) → 프로토타입 테스트 → 모델 성능(macro-F1·recall) → 효과(사용 전후 SPANE) → 리텐션·바이럴(D1/D7·K계수)

**핵심 검증 질문**

1. 사용자가 설문 없이 대화만으로 나온 결과카드를 "나 같다"고 느끼는가?
2. 결과카드를 저장하거나 공유하고 싶은가?
3. 캐릭터가 나를 기억한다는 느낌이 재방문으로 이어지는가?
4. 위기/고위험 대응이 과하거나 차갑지 않은가?
5. 유료 카드/리포트에 결제 의향이 있는가?

**초반 실험 지표**

| 단계 | 지표 |
|---|---|
| 진입 | 첫 문장 입력률, 캐릭터 대화 시작률 |
| 대화 | 5턴 이상 유지율, 중도 이탈 지점 |
| 결과 | 결과카드 생성률, 저장률, 공유 클릭률 |
| 재방문 | D1/D7 재방문, 주간 카드 조회율 |
| 신뢰 | 안전 안내 적중률, 불쾌/부담 피드백률 |

## 20. 리스크 & 대응

| 리스크 | 설명 | 대응 |
|---|---|---|
| 위기 미탐(자살 등) | 자해/자살 표현을 놓치면 위험 | 다층 방어 + LLM 우회 + recall 우선 + 레드팀(12장) |
| 척도 추정 정확도 | 자유 대화만으로는 오차 발생 | 앵커 보정 + "점수 아닌 위로"로 흡수 |
| 의료기기·광고 규제 | 척도·정신건강 표현이 진단처럼 보일 수 있음 | 비의료 포지셔닝, 진단·효능 표방 금지, 점수 비노출 |
| 민감정보 신뢰 | 마음 대화는 매우 민감함 | 시크릿챗(비저장)·동의·암호화·선택형 메모리 |
| 과의존 | 캐릭터 관계가 지나치게 깊어질 수 있음 | 쉬어가기, 현실 연결, 이너 카운슬로 단일 의존 완화 |
| 큰 회사 추격 | 크랙·ingan 등이 결과카드를 붙일 수 있음 | 숨은 척도 엔진·안전 정책·누적 결과지·심리 RAG를 빠르게 구축 |
| 데이터 라이선스 | 비상업·카피레프트 데이터 혼입 | 상업 가능(공공·퍼블릭·MIT·자체)만, 비상업/카피레프트 제외 |
| GPT 비용 | API 비용 증가 | 모델 분리·한도 설정 |
