# 빈틈사이 온보딩 시퀀스 다이어그램

기준 화면: 메인페이지, 밸런스게임, 로그인, 캐릭터 설정, 사용자 정보 입력, 밸런스게임 결과, 카드 운세, 캘린더

이번 수정본은 카드 운세 기능에서 **생년월일 기반 운세 프로필 계산**, **관계/재물/성공/직업운 4개 카테고리 결과 생성**, **카드 4~5장 선택**, **LLM 조언 실패 시 기본 템플릿 반환**, **위험 신호/확정적 예언 표현 필터링** 흐름을 반영한다.

```mermaid
sequenceDiagram
  autonumber
  actor U as 사용자
  participant App as Vue App<br/>해시 라우터
  participant Home as 메인페이지<br/>#home
  participant Balance as 밸런스게임<br/>#balance
  participant Login as 로그인<br/>#login
  participant Character as 캐릭터 설정<br/>#character
  participant UserInfo as 사용자 정보 입력<br/>#userinfo
  participant Result as 밸런스게임 결과<br/>#result 예정
  participant Fortune as 카드 운세<br/>#fortune
  participant Calendar as 캘린더<br/>#calendar
  participant Store as 사용자 데이터/API
  participant FortuneSvc as FortuneService<br/>운세 계산/카드 생성
  participant AI as AI 분석/LLM
  participant Safety as 안전 필터<br/>표현/위험 신호 검사

  U->>App: 서비스 접속
  App->>Home: 기본 라우트 #home 렌더링
  Home-->>U: 히어로 CTA, 밸런스게임, 카드 운세, 상단 캘린더 진입점 표시

  alt 온보딩 시작: 산책 시작하기
    U->>Home: 산책 시작하기 클릭
    Home->>App: navigate("login")
    App->>Login: 로그인 화면 렌더링
    U->>Login: 소셜/이메일 로그인 선택
    Login->>Store: 인증 요청 및 사용자 상태 조회
    Store-->>Login: 로그인 성공 + 첫 설정 필요 여부 반환

    alt 첫 로그인 사용자
      Login->>App: navigate("character")
      App->>Character: 캐릭터 설정 화면 렌더링
      U->>Character: 동행자, 표정, 대화 톤 선택
      Character->>Store: 캐릭터/페르소나 임시 저장
      Character->>App: navigate("userinfo")
      App->>UserInfo: 사용자 정보 입력 화면 렌더링
      U->>UserInfo: 이름, 생년월일, 현재 상태, 관심사 입력
      UserInfo->>Store: 프로필/관심사 저장
      Store-->>UserInfo: 저장 완료
      UserInfo->>App: navigate("chat")
      App-->>U: 대화 시작 화면으로 진입
    else 기존 사용자
      Login->>App: 이전 목적지 또는 홈/대화로 이동
      App-->>U: 저장된 캐릭터와 프로필 설정으로 화면 렌더링
    end
  end

  alt 온보딩 콘텐츠: 심리 밸런스 게임
    U->>Home: 심리 밸런스 게임 클릭
    Home->>App: navigate("balance")
    App->>Balance: 밸런스게임 화면 렌더링

    loop 질문 1~N
      U->>Balance: A/B 선택
      Balance->>Store: 선택값 임시 저장
      Store-->>Balance: 진행률/선택 상태 갱신
    end

    Balance->>AI: 성향 분석 요청(선택값)
    AI-->>Balance: 대표 성향, 그래프, 키워드 반환
    Balance->>App: navigate("result")
    App->>Result: 밸런스게임 결과 화면 렌더링
    Result-->>U: 성향 타입, 요약, 그래프, 다음 행동 표시

    opt 결과 저장이 필요하고 미로그인 상태
      Result->>App: navigate("login")
      App->>Login: 로그인 화면 렌더링
      U->>Login: 로그인 완료
      Login->>Store: 결과 저장 요청
      Store-->>Result: 저장 완료
    end
  end

  alt 온보딩 콘텐츠: 카드 운세 보기
    U->>Home: 카드 운세 보기 클릭
    Home->>App: navigate("fortune")
    App->>Fortune: 카드 운세 화면 렌더링
    Fortune->>Store: 사용자 프로필/관심 키워드/최근 밸런스 결과 조회
    Store-->>Fortune: 생년월일, 성향 요약, 관심 키워드 반환

    alt 생년월일이 없는 사용자 또는 비로그인 사용자
      Fortune-->>U: 생년월일 입력 폼 표시
      U->>Fortune: 생년월일 입력
      opt 로그인 사용자
        Fortune->>Store: USER_PROFILE.birthday 저장 또는 갱신
        Store-->>Fortune: 저장 완료
      end
    end

    U->>Fortune: 운세 카테고리 선택<br/>relationship/money/success/job
    Fortune->>Store: POST /fortune/cards<br/>birthDate, category, readingDate
    Store->>FortuneSvc: 카테고리 검증 및 운세 프로필 계산
    FortuneSvc->>FortuneSvc: 생년월일 기반 간이 계산<br/>연간/연지, 오행, seed, formulaVersion
    FortuneSvc->>FortuneSvc: 카테고리별 결과 4종 생성<br/>관계/재물/성공/직업
    FortuneSvc-->>Store: 선택 카테고리 카드 4~5장 + categoryResult 반환
    Store-->>Fortune: 카드 목록, 오늘 흐름, 주의사항 반환
    Fortune-->>U: 카드 4~5장 표시

    U->>Fortune: 카드 1장 선택
    Fortune->>Store: POST /fortune/advice<br/>categoryResult, selectedCard, persona, interests
    Store->>Safety: 위험 신호 사전 감지

    alt 위험 신호 감지
      Safety-->>Store: 일반 운세 대신 안전 안내 필요
      Store-->>Fortune: safety 안내 문구 반환
    else 위험 신호 없음
      Store->>AI: LLM 조언 생성 요청<br/>성향/관심 키워드/카드 의미/context
      alt LLM 성공
        AI-->>Store: 1~3문장 조언 반환
      else LLM 실패 또는 타임아웃
        Store->>FortuneSvc: 기본 조언 템플릿 생성
        FortuneSvc-->>Store: fallbackAdvice 반환
      end
      Store->>Safety: 확정적 예언 표현 필터링
      Safety-->>Store: 안전한 조언 문구 반환
      Store-->>Fortune: cardMeaning, todayFlow, caution, advice 반환
    end

    Fortune-->>U: 선택 카드 결과와 LLM/기본 조언 표시

    opt 운세 저장
      Fortune->>Store: POST /fortune/readings<br/>결과 저장 요청
      Store->>Store: FORTUNE_READING 생성<br/>FORTUNE_ADVICE_LOG 저장
      Store->>Store: CALENDAR_ENTRY 생성 또는 갱신
      Store-->>Fortune: 저장 완료
      Fortune-->>U: 캘린더 저장 완료 표시
    end
  end

  alt 상단바 진입: 캘린더
    U->>App: 상단바 캘린더 클릭
    App->>Calendar: navigate("calendar") 후 화면 렌더링
    Calendar->>Store: 날짜별 감정/운세/대화 기록 조회
    Store-->>Calendar: 월간 기록, 선택 날짜 상세, 주간 그래프 반환
    Calendar-->>U: 캘린더와 일자 상세 표시
    U->>Calendar: 특정 날짜 클릭
    Calendar->>Store: 해당 날짜 FORTUNE_READING 상세 조회
    Store-->>Calendar: 운세 카테고리, 선택 카드, 조언, 안전 상태 반환
    Calendar-->>U: 감정 한줄평, 카드 운세, 주간 감정 그래프 갱신
  end

```

## 메모

- 현재 Vue 구현은 `#home`, `#balance`, `#login`, `#fortune`, `#calendar`, `#character`, `#userinfo` 라우트를 포함한다.
- `#result`는 화면설계서의 성향결과 화면을 반영한 예정 라우트로 표시했다.
- 캐릭터 설정과 사용자 정보 입력은 첫 로그인 때만 수행하고, 기존 사용자는 저장된 설정으로 건너뛴다.
- 카드 운세는 생년월일을 기반으로 `FORTUNE_PROFILE`을 만들고, 같은 계산 결과에서 `relationship`, `money`, `success`, `job` 4개 카테고리 결과를 생성한다.
- LLM은 운세 계산 자체를 담당하지 않고, 계산 결과/카드 의미/성향/관심 키워드를 받아 1~3문장 조언만 생성한다.
- LLM 실패 시 `FortuneService`의 기본 조언 템플릿을 사용한다.
- 위험 신호가 감지되면 일반 운세 조언 대신 안전 안내를 반환한다.
- 확정적 예언 표현은 저장 및 표시 전에 필터링한다.
