Description
  1. ① 마음 리포트 보관함 (기간 선택) — 발급받은 주간·월간 리포트의 기간(날짜) 목록. 기간 클릭 시 우측 화면과 하단 감정일기에 해당 주/월 상세 분석이 연동 표시.
  2. ② 감정 일기 (시계열 감정 변화 흐름) — ①에서 선택한 기간(주간 7일 / 월간 30·31일) 동안 매일 기록된 대표 감정을 이모지로 시각화.
  3. ③ 리포트 타이틀 영역 — 조회 중인 리포트 단위(예: 주간/월간 리포트)를 명시.
  4. ④ 핵심 원인 키워드 (토픽 모델링) — 누적 대화를 자체 ML 파이프라인(BERTopic 등)이 분석. 부정 '스트레스 주요 원인'·긍정 '이완 원인'을 단어 묶음으로 렌더링.
  5. ⑤ 객관적 상황 분석 (LLM 텍스트) — 키워드 + 맥락 기반 외부 LLM이 종합 분석 생성. 섣부른 위로 배제, 감정 패턴 메타인지·대처 제안.
  6. ⑥ 리포트 내보내기 — 리포트 영역 캡처 → 이미지 저장/공유.
Check Point
  • 기획 원칙: 섣부른 위로 배제, 객관적 상황 분석 중심
  • 점수·진단명 등 임상 표현 비노출 (추정 ≠ 진단)
  • 기간 미선택/기록 부족 시 빈 상태 문구 + 기록 유도
  • 공유 캡처 시 이름·민감 정보 마스킹, 시크릿챗 기록 제외
