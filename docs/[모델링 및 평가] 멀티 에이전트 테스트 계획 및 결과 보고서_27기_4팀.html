1. 테스트 개요 및 환경 설정

1.1 테스트 목적 및 범위 정의

본 보고서는 마음리포트(MindReport) 서비스를 구현하는 LangGraph 멀티 에이전트 아키텍처의 구체적인 구현 코드와 전체 53개 단위/통합 테스트 스위트의 실측 수행 결과를 바탕으로 작성되었습니다. 특히 LangGraph 기반의 상태 유지(MindReportGraphState) 정합성, Neo4j 장기 기억 그래프 DB(LTM) 및 PostgreSQL RAG 데이터베이스의 검색 정확도, sLLM(KcELECTRA)의 도메인 특화 감정 분류 성능 및 소스코드의 모듈화 구조를 검증합니다.

1.2 기술 스택 및 테스트 환경

구분상세 스펙
Language & FrameworkPython 3.11/3.14, LangChain v0.2.3, LangGraph v0.1.5 (StateGraph)
LLM / sLLMFine-tuned KcELECTRA-v2 (감정 점수화/4감정 분류, Macro-F1 0.78), GPT-4o-mini (서사/대안/검증 에이전트)

1.3 에이전트 구성 개요

Supervisor Agent (MindReportSupervisorAgent / graph_flow.py): 사용자 의도 파악(Criteria Check) 및 MindReportGraphState 기반 태스크 분할, 라우팅 및 Revision/Fallback 전체 오케스트레이션 수행.
Criteria Agent (MindReportGenerationCriteriaAgent / criteria_agent.py): 주간(5건 이상) 및 월간(20건 이상) 사용자 대화 수량을 판단하여 정식 분석 경로 또는 Fallback 분기 선택.
Emotion Analysis Agent (MindReportEmotionAnalysisAgent / emotion_analysis_agent.py): fine-tuned KcELECTRA sLLM 기반 4감정 점수화 및 시계열 감정 흐름 분석.
Cause Keyword Agent (MindReportCauseKeywordAgent / cause_keyword_agent.py): 대화 맥락 기반 원인 키워드 후보 추출, 스트레스/이완 원인 분류 및 라벨 표출 정책 결정.
Narrative Action Agent & Validation Agent: 대화 근거 분석 서사문 및 실천 대안 생성, PII 및 의료 진단 표현 100% 검수 및 Revision 제어.
