# 데이터 정제 명세서

> 공통 원칙: **버리는 것에는 이유가 있어야 하고, 그 이유는 숫자로 기록한다.**
> AI Hub 파생물은 재배포 금지 → 파일 대신 정제 스크립트를 배포 (repo에서 재생성 가능).

## 1. `kcelectra_train_clean.jsonl` — 학습 본셋 (58,234건)

| 항목 | 내용 |
|---|---|
| 원천 | AI Hub 감성대화 말뭉치 58,268 대화 (Training 51,628 + Validation 6,640) |
| 추출 | 첫 사람 발화(HS01) + 감정 대분류(E코드 첫째 자리) |
| 제외 ① | 시스템 응답(SS)·후속 턴(HS02~) — **학습 입력 = 서빙 입력(사용자 문장 하나) 원칙**. 응답은 LLM이 생성하므로 불필요 |
| 제외 ② | 연령·성별·상황·질병 메타 — 서빙 시점에 알 수 없는 정보라 학습 특징으로 쓰면 재현 불가 |
| 제외 ③ | 세부 60감정 — 4모드 톤 라우팅에는 대분류로 충분, 세부화하면 클래스당 표본 부족 |
| 정제 | 공백 정규화(\xa0·다중 공백) → 완전 중복 17건 제거 → 라벨 상충 문장 17건 단일화(최초 등장 유지) |
| 검증 | 원천 대비 **100.000% 계보 일치** (EDA §0-2) |
| 재생성 | `python ai/emotion/rebuild_clean_dataset.py --raw <원천>/018.감성대화` |

상세 근거: `ai/emotion/EDA_감정분류_김한솔.ipynb` §0~§7.

## 2. `chat_eval_set.jsonl` — 채팅체 평가셋 (60건 · 자체 제작)

| 항목 | 내용 |
|---|---|
| 목적 | 학습 데이터(2020 크라우드 작성체)와 실사용 입력(채팅체)의 문체 간극 검증 — **"지표가 낮아도 실사용에선 나을 수 있다" 가설의 판정지** |
| 구성 | 4감정 × 15문장 균형. 실제 채팅 문체(반말·축약·"ㅋㅋ")로 작성 |
| 설계 의도 | 함정 문장 포함 — 중립 단문("점심에 김치찌개 먹었어" ← 실측 오분류 사례), 초단문("응 ㅋㅋ", "몰라") |
| 사용 규칙 | **평가 전용, 학습 투입 절대 금지** (시험지 오염 방지) |
| 한계 | ⚠ 라벨은 작성자 1인 초안 — **팀 검수 필수**. 60건은 판정력 부족(문항 몇 개 차이로 F1 ±0.1 출렁임) → **150건 이상으로 증량 권장** |

## 3. `aug_voice.jsonl` — 실험② 추가 후보: 음성 대화 전사 (36,677건)

| 항목 | 내용 |
|---|---|
| 원천 | AI Hub 감정 분류를 위한 대화 음성 (4·5차년도 CSV, 43,991 발화) — 텍스트 전사만 사용 |
| 라벨 규칙 | 어노테이터 5명 투표에서 **3표 이상(과반) 합의된 발화만** 채택 |
| 왜 3표인가 | 투표 분포: 5표 만장일치 13,627 / 4표 11,314 / 3표 11,739 / **2표 이하 7,311**. 2표는 5명 중 3명이 다르게 봤다는 뜻 = 사람도 못 가르는 문장 → 학습에 넣으면 라벨 노이즈 |
| 제외 | 합의 미달 7,311건(16.6%) + 2자 미만 무효 발화 |
| 7→4 매핑 | happiness→기쁨, sadness→슬픔, angry·disgust→분노, **fear→분노**, neutral→일반, **surprise→일반** — 감성대화의 기존 규칙(불안→분노, 당황→일반)과 일관성 유지가 근거 |
| 재생성 | `python ai/emotion/prepare_aug_datasets.py --voice-dir <원천 폴더>` |

## 4. `aug_wellness.jsonl` — 실험② 추가 후보: 웰니스 상담 발화 (1,002건)

| 항목 | 내용 |
|---|---|
| 원천 | AI Hub 웰니스 대화 스크립트 5,231건 (구분 카테고리 + 유저/챗봇 발화) |
| 채택 | `감정/*` 카테고리 1,620건 중 하위명이 4모드로 명확히 매핑되는 1,002건의 **유저 발화만** |
| 제외 ① | 비감정 카테고리 3,611건(배경·증상·치료이력 등) — 감정 라벨이 아니라 상담 맥락 분류라서 감정 정답으로 쓸 수 없음 |
| 제외 ② | 감정 하위 중 미매핑 618건 — 두 부류: (a) **본질적으로 모호**: 부정적사고(93)·심란(34)·생각(30)·모호함(19)·신경쓰임(17) 등 — 어느 감정인지 카테고리명만으로 판정 불가 (b) **보수적 제외**: 자괴감(27)·무서움(24)·절망감(18)·서운함(20) 등 — 매핑 가능성은 있으나 규칙 확장 없이 제외. 규칙을 넓히면 +200~300건 회수 가능 (개선 여지로 기록) |
| 알려진 한계 | ⚠ **기쁨 12건뿐** — 상담 데이터 특성상 부정 감정 편중. 추가 시 불균형 심화 예상 → 그래서 "실험으로 확인 후 채택"(계획서 §4 원칙) |
| 재생성 | `python ai/emotion/prepare_aug_datasets.py --wellness <xlsx 경로>` |

## 5. 요약 — 무엇을 왜 버렸나 (한 장)

| 데이터 | 들어옴 | 버림 | 버린 이유 한 줄 |
|---|---|---|---|
| 감성대화 | 58,234 | 34 | 중복·라벨 상충 (사람도 라벨을 못 가른 문장) |
| 음성 전사 | 36,677 | 7,314 | 5명 중 과반 합의 실패 = 라벨 노이즈 |
| 웰니스 | 1,002 | 4,229 | 감정 라벨이 아니거나(3,611) 카테고리가 모호(618) |
| 채팅체 평가셋 | 60 | — | 자체 제작 (검수·증량 필요) |

**철학**: 양보다 라벨 확실성. 애매한 라벨을 버리는 건 데이터 손실이 아니라 노이즈 제거다 —
단, 버린 것의 목록과 규모를 남겨 언제든 재검토할 수 있게 한다.
