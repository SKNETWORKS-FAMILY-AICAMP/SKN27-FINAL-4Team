1. 테스트 개요 (Test Overview)

1.1 테스트 목적

본 테스트의 목적은 LangGraph 기반의 마음리포트(MindReport) 멀티 에이전트 협업 체계(MindReportSupervisorAgent)와 감성 분석 sLLM/KcELECTRA, Neo4j 장기 기억 그래프 DB(LTM), 외부 API(Tavily Search API) 연동의 서비스 안정성, 정확도 및 모듈화 구조를 배포 단계에서 최종 검증하는 데 있습니다. 구현된 에이전트가 설계 의도대로 동작하는지 전체 53개 단위/통합 테스트 스위트를 구동하여 검증하였으며, 에이전트 간의 상태(MindReportGraphState) 전이, 검증 에이전트(MindReportValidationAgent)를 통한 안전성 및 할루시네이션 방지 체계, 그리고 소스코드가 기능별로 잘 모듈화되었는지 점검합니다.

1.2 테스트 범위 및 대상 기능

테스트는 사용자 대화 데이터 수집(Criteria Check)부터 에이전트 오케스트레이션, 검증 루프, 렌더링 응답 생성(ReportView.vue)까지의 전 과정을 포함하며, 다음 핵심 기능을 중점적으로 검증합니다.

분류테스트 대상 기능 (Checklist)주요 검증 포인트
데이터 수집/저장MySQL 및 Neo4j Graph DB 적재ChatMessage/MindReport PK 정의, 데이터 무결성, 비정형 사용자 대화 원문 저장 및 LTM Graph Memory(Episode/Event/Person/Emotion) 연동 구조
데이터 전처리의도 분석 및 감정 분류 ML/DL 모델요청 대화의 감정 상태(Affect/Score) 산출 및 감정 흐름(Score Upward/Downward/Volatile/Maintenance) 패턴 분류 성능
RAG/에이전트LangChain/LangGraph 협업 로직MindReportSupervisorAgent의 조건부 라우팅 정확도, 에이전트 간 상태 유지(MindReportGraphState Pipeline) 및 검증 실패 시 재시도(Revision Loop) / Fallback 분기
외부 연동Tavily Search API / Web Agent 연동외부 검색 도구(FallbackWebAgent) 호출 체계 및 데이터 부족/활동 추천 연동 정보 처리 신뢰성
보안 및 UI프론트엔드-백엔드-LLM 통합PII 및 의료 진단/단정 표현 필터링(Safety Response), 대화 원문 마스킹, 웹 프로그램 상의 차트/감정카드 시각화 정합성

3. 테스트 상세 계획 (Test Scenarios & Methods)

사용자 요청부터 최종 리포트 생성까지의 정상 워크플로우를 총 53개 단위/통합 테스트 스위트 기반으로 검증합니다. 모든 테스트는 Session ID / User ID를 기반으로 로그를 추적하여 에이전트 간 데이터 전달의 일관성을 확인합니다.

3.2 예외 상황 테스트 (Edge Cases & Failure Mode)

ID테스트 항목검증 및 기대 결과 (Imperative)
ERR-RAG-01RAG/LTM 검색 실패 (기억 미존재 또는 DB 장애)Neo4j LTM Graph Memory 조회 실패 시에도 그래프 recall 예외를 안전하게 포획(catch)하고, 세션이 중단되지 않으며 최근 대화 원문만으로 무중단 분석을 진행하는지 확인하라.

ERR-MCP-01외부 API (Tavily/OpenAI) 장애Tavily API 타임아웃 또는 API 키 미설정 시 static dummy 추천 대신 안전하게 빈 리스트([])를 반환하고 데이터 수집 안내 문구를 출력하는지 확인하라.
ERR-HALU-01할루시네이션 및 안전성 위반 (의료 진단/직접 인용)생성된 서사에 '우울증', '치료' 등 의료 진단/단정 표현이나 대화 원문 직접 인용, 감정 점수 무단 노출이 포함될 경우 ValidationAgent가 이를 즉시 감지하여 수정(needs_revision) 또는 차단(blocked)하는지 검증하라.
